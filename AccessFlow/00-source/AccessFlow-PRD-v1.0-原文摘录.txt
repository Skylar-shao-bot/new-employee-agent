1. 产品概述
1.1 产品定位
AccessFlow 是一个帮助用人经理为新员工准备公司账号、日常工具和项目权限的 Web 端 Agent 工作台。经理使用自然语言提出需求后，Agent 核对人事信息、岗位模板、权限规则和审批状态，生成开通方案；经理确认后，系统推进必要审批和跨系统开通，并逐项展示执行结果。
1.2 核心场景
经理原始需求9 月 7 日，陈晨将作为软件产品设计师加入上海产品研发部，参与 Atlas 项目。请参考同岗位员工，在第一天 9:00 前把公司账号、日常工具和项目权限准备好，尽量别反复问我。
1.3 现状与价值
人工处理一次需要 60-90 分钟。
28% 的员工第一天仍缺账号或权限。
12% 的任务出现部分失败、重复申请或状态不明。
同岗位员工的历史特殊权限可能被错误复制。
多系统、审批和依赖缺乏统一进度视图。

5. 核心设计原则与流程
最小权限：不得因为同岗位员工拥有特殊权限，就向陈晨授予相同权限。
状态分离：Agent 建议、经理确认、审批人批准和系统实际开通是四个不同事实。
先确认后执行：经理确认前，Agent 只能核对和生成方案。
依赖控制：公司账号成功后，才能执行依赖账号的其他项目。
幂等与防重复：成功项不得重复执行；结果未知时必须先查询。
逐项记录：每项分别记录编号、审批、时间、结果、原因和可用操作。
5.1 主流程
体验主线经理输入 -> DeepSeek 理解 -> Agent 读取模拟上下文 -> 生成方案 -> 经理审阅和确认 -> 直接执行/等待审批 -> 跨系统进度 -> F01 部分完成 -> 查询未知结果或处理失败项。
6. 功能需求
FR-01 需求输入
经理可以输入自然语言需求。提交后出现明确加载状态，后端调用 DeepSeek-V4-Flash 理解需求，并在成功后进入方案审阅。输入和最终结果页面可较低保真。
输入为空时不能提交。
加载时说明 Agent 正在核对什么。
API 失败时保留原始输入并支持重新生成。
缺失信息时只询问影响方案或执行的必要内容。
FR-02 开通方案审阅（1440px 高保真）
展示陈晨的岗位、部门、经理、入职日期、项目及截止日期。
清楚区分岗位标准、用户申请、Agent 建议和被排除权限。
七项建议分别显示权限范围、理由、来源、依据、风险、依赖和审批需求。
明确排除客户数据导出和生产系统管理，并解释历史权限不能照搬。
展示缺失信息、信息冲突、规则冲突和修改入口。
页面验收经理能在 30 秒内识别建议项、排除项及理由；排除权限不能被误认为待执行权限；状态不能只依赖颜色。
FR-03 权限与执行确认（1440px 高保真）
每项展示目标系统、权限级别、有效期、风险、依赖、审批要求、审批人角色和执行条件。按“可直接执行 / 需要审批 / 不应开通”分组。
主操作为“确认方案并开始处理”。
该操作记录经理确认，启动允许直接执行的项目，将审批项目置为待审批。
被排除项目不得进入执行队列。
经理确认与负责人审批必须分别展示。
FR-04 跨系统执行进度（1440px 高保真）
页面同时展示整单状态和七项进度，支持成功、执行中、待审批、被阻塞、需要用户处理、失败和结果未知。
每项说明 Agent 正在做什么、调用哪个系统、谁在处理、下一步是什么。
展示申请编号、开始时间、最近更新时间、原因和可用操作。
公司账号执行期间，依赖项显示等待原因；成功后才解除阻塞。
使用现有页面中的详情抽屉展示工具名称、操作、调用编号、原因码和允许操作。

9. 技术架构与模型接入
9.1 演示架构
调用链AccessFlow Web -> 轻量 Agent API -> DeepSeek-V4-Flash -> Tool Router -> Mock Connector -> 模拟人事、审批及七个目标系统。确定性状态和安全规则由轻量 Agent API 控制。
9.2 DeepSeek-V4-Flash
模型 ID：deepseek-v4-flash。
基础地址：https://api.deepseek.com。
使用兼容 OpenAI Chat Completions 的接口格式。
模型负责解析自然语言、调用上下文工具、生成结构化方案和理由说明。
后端必须校验工具参数和模型输出，不能把模型输出直接视为授权事实。
9.3 确定性后端职责
强制经理确认、审批规则和依赖关系。
生成申请编号并维护整单与单项状态。
固定返回 F01 结果。
成功项拒绝重复执行；未知项拒绝直接重试。
向前端返回 allowedActions，前端不得自行猜测可用操作。

9.5 安全要求
DeepSeek API Key 只存在于服务端环境变量，不进入前端、Git、日志、截图或 PDF。
发送给模型的数据均为题目提供的模拟数据。
不得向模型发送真实员工个人信息。
工具调用参数必须在服务端验证，越权请求必须拒绝。
