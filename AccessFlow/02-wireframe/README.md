# AccessFlow 静态工作台

首页（P-01）、开通方案审阅（P-02）、权限与执行确认（P-03）、执行进度（P-04）与执行结果（P-05 / F01）已按同一套 SideLayout 落地。数据写死陈晨案例，不接后端。

顶部流程为 **4 步**：新建开通 → 开通方案审阅 → 权限与执行确认 → **执行进度 / 执行结果**（第四步标题随阶段切换）。

## 启动

```bash
cd AccessFlow/02-wireframe
npm install
npm run dev
```

浏览器打开 http://localhost:5173 。预填陈晨原句可访问 `/?demo=chenchen`，生成成功后进入 `/plan`。审阅页点「继续确认执行」进入 `/confirm`，确认后进入 `/progress`。进度页会 mock 推进各系统状态；未凑齐时可用「稍后处理」离开，凑齐 F01 后标题切为「执行结果」并自动进入 `/f01`。也可从侧栏「开通记录」直接打开 http://localhost:5173/f01 。

## 本阶段范围

- `/` 需求输入首页
- `/plan` 开通方案审阅
- `/confirm` 权限与执行确认
- `/progress` 执行进度（mock 推进 → 自动进入结果）
- `/f01` 执行结果（F01 部分完成）
- `/result` 最终结果摘要（仍为部分完成）
