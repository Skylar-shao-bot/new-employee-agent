## 核心假设 / 本阶段目标

用人经理用一句自然语言，就能在确认后完成新员工账号与权限开通；Agent 可以自动核对和执行，但不能越权、不能把确认当成审批、不能把部分完成显示成全部完成。

本期要验证的不是“能不能接真实企业系统”，而是：**经理能不能在 30 秒内看懂方案差异，并在部分失败时知道下一步该谁处理。**

## MVP 本期范围（来自 v1.0 冻结）

1. 需求输入 → Agent 核对 → 生成方案  
2. 经理审阅 / 修改 / 确认  
3. 按条件分流：可直接执行 或 等待审批  
4. 跨系统执行，固定走到 F01 部分完成  
5. 查看逐项结果与最终结果  

不做：审批人端、员工端、真实系统、批量开通、独立记录列表、邮件催办。
